# Метеоритный рейс — браузерная версия

Браузерный порт игры «Космическая астероидная оборона» (Python/Pygame, `game.py`).
Статический HTML/CSS/JavaScript с Canvas: без сборки, без серверной части, без внешних ресурсов —
вся графика рисуется процедурно, весь звук генерируется через Web Audio API на лету.

## Содержимое

```
browser/
├── index.html   — точка входа
├── style.css    — стили, оверлеи (меню/пауза/результат)
├── js/
│   ├── config.js   — константы, характеристики секторов и босса, DEBUG-режим
│   ├── sound.js    — процедурный звук (Web Audio) + эмбиент + выключение звука
│   ├── input.js    — клавиатура, запрет прокрутки страницы игровыми клавишами
│   ├── star.js     — параллакс-фон
│   ├── ship.js     — корабль игрока
│   ├── laser.js    — лазеры игрока
│   ├── asteroid.js — астероиды (big/small, прочные — несколько попаданий)
│   ├── particle.js — частицы взрывов
│   ├── powerup.js  — бонусы: щит и двойной выстрел
│   └── boss.js     — финальный босс (2 фазы), его пули и полоса HP
└── README.md
```

## Игровой цикл

1. Начальный экран: название, управление, лучший результат, кнопка «Играть».
2. Три сектора по 30 секунд активной игры (номер сектора и таймер в HUD):
   - Сектор 1 — обычные астероиды;
   - Сектор 2 — больше и быстрее;
   - Сектор 3 — быстрые и крупные, выдерживающие несколько попаданий.
3. Финальный босс: большой корабль с полосой HP, горизонтальным движением и
   выстрелами; при 50% HP переходит во вторую фазу (учащённый огонь, веерные
   залпы в сторону корабля).
4. Из уничтоженных астероидов выпадают бонусы:
   - щит — поглощает одно попадание (не складывается);
   - двойной выстрел — 10 секунд, повторное получение обновляет таймер.
5. Пауза по `P`; при потере фокуса окна — автоматическая пауза.
   Возобновление только действием игрока.
6. После победы или поражения — итоговый счёт и рекорд (localStorage).

Управление: `←` `→` — движение, `Space` — огонь, `P` — пауза, `Esc` — в меню.
Кнопка «Звук» включает/выключает озвучку (звук стартует только после первого
действия игрока).

## Локальный запуск

Файл `index.html` открывается без сервера, но из-за политик браузера стабильнее
запускать через HTTP. Из папки проекта:

```bash
# вариант 1: браузерная версия как корень
cd browser
python3 -m http.server 8000
# открыть http://localhost:8000/

# вариант 2: корень проекта (имитация подпапки /repository/)
python3 -m http.server 8000
# открыть http://localhost:8000/browser/
```

Любой другой статический сервер (`python3 -m http.server`, `npx serve`) подойдёт.

## Публикация на GitHub Pages

Игра опубликована: **https://eeealesha.github.io/meteorite-raid-game/**

Деплой автоматический: workflow `.github/workflows/pages.yml` на каждый push в `main`
берёт содержимое папки `browser/` и публикует его как статический сайт Pages
(`actions/upload-pages-artifact` → `actions/deploy-pages`). Сборки нет — на сайт
попадают ровно те файлы, что лежат в репозитории.

Особенности:

- публикуется содержимое `browser/`, поэтому адрес игры — без `/browser/` в пути;
- все пути внутри игры относительные (`./`), поэтому она работает и в подпапке,
  например при локальном запуске из корня проекта: `http://localhost:8000/browser/`;
- если после обновления видна старая версия — обновите страницу с очисткой кэша;
- рекорд хранится в `localStorage`: у каждого игрока он свой, общего лидерборда нет.

## Режим проверки (DEBUG)

Для быстрой проверки поздних этапов без прохождения всей игры откройте
`js/config.js` и установите нужные флаги:

```js
const DEBUG = {
    enabled: false,        // поднять на true, чтобы включить режим проверки
    skipToSector: 0,       // 1/2/3 — начать с сектора, 4 — сразу босс
    sectorTimeOverride: 0, // > 0 — сократить сектор (например, 2 = две секунды)
    godMode: false,        // неуязвимость
    instantPowerups: false,// бонус при каждом уничтоженном астероиде
    bossHp: 0,             // > 0 — сократить здоровье босса (например, 2)
};
```

Режим явно отделён от обычной игры и выключен по умолчанию (`enabled: false`):
при выключенном флаге лишние тестовые возможности не загружаются.

## Тесты

Автоматических тестов в проекте нет. Проверка проводилась headless-прогревом
всех модулей со стабами DOM/canvas/audio (оставлен вне репозитория). Для ручной
проверки: меню → игра → сектора → босс, а также пауза, ячейка бонусов, рестарт
и сохранение рекорда между перезагрузками страницы.
